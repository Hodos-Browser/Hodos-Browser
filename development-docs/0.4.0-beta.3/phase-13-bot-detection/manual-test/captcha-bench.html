Hodos CAPTCHA bench

Three real widgets, using each vendor's public test keys. Open this in Hodos and in Chrome side by side.

What this page does and does not prove.
Test keys are configured to always pass. So this page answers “does the widget load, run and complete in Hodos?” — which is exactly the Brave failure mode, where the checkbox spins or reloads forever.
It does not answer “does a real site trust us”, because no real risk decision is being made — and for the same reason you will never see a pick-the-bicycles image grid here. Test keys always pass, and real risk-scoring sitekeys are domain-locked so they cannot be embedded on localhost. For grids, go to https://2captcha.com/demo/recaptcha-v2 (a live widget with a real sitekey) or any sign-up flow — see HOW_TO_TEST_BY_HAND.md.
